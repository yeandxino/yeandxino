## 🧠 我怎么解决问题

我的习惯是三步：**先把问题量化 → 再让代码兜底 → 最后才调 Prompt。**

- 大模型编造结论 → 在代码层校验结论能否追溯到统计量
- 模型传参忽 `file_path` 忽 `path` → 工具层做参数名兼容，传什么都跑得起来
- 检索老召回目录页 → 代码层加过滤函数，而不是反复改提示词
